# OpenRST (ROS 2 Jazzy) — Fork actualizado

Este repositorio es un **fork de OpenRST** que se actualizó desde la versión original en ROS 1 para **funcionar en ROS 2 Jazzy** e integrarse con el proyecto principal de simulación y asistencia quirúrgica:

- Proyecto principal: https://github.com/jhulio435m/ur10e_ROS2-UNCP

## Propósito del fork

- Migrar la base de OpenRST a **ROS 2 Jazzy**.
- Mantener compatibilidad con el ecosistema del proyecto principal (UR10e + Unity + herramientas quirúrgicas).
- Servir como componente de instrumentación quirúrgica dentro del stack de simulación.

## Estado del repositorio

- La documentación original del proyecto OpenRST se conserva en `docs/README.md`.
- Este fork se centra en la adaptación técnica para ROS 2 (Jazzy) y su integración con el sistema principal.
